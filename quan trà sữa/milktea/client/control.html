Kết nối TikTok LIVE

Chỉ đọc sự kiện công khai của phòng live. Không cần mật khẩu hay cookie. Rớt mạng sẽ tự nối lại cho tới khi bấm Ngắt.

Server đang chạy chế độ giả lập nên chưa kết nối TikTok được. Tắt cửa sổ server rồi chạy npm start trong thư mục milktea (hoặc nhấp đúp mo-tra-sua.cmd), sau đó tải lại trang này.

Âm thanh

Tiếng phát ở cửa sổ màn hình game (cửa sổ bạn đưa vào TikTok LIVE Studio). Giọng đọc cần Internet. Nhạc nền tự tạo, không dùng bài hát có bản quyền.
