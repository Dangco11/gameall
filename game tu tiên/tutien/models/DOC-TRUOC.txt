THAY BẰNG MODEL KHÁC
  - Tu sĩ riêng cho một lớp: <lớp>.glb hoặc <lớp>_nu.glb (kiemtu, daotu, phapsu, matu, tiennu, longtoc, yeutoc, thetu,
    tranphap, luyendan, kiemtien, mavuong, thienton, loitu, banghoa). Có file này thì lớp đó dùng nó thay cho tusi-*.glb.
  - Boss: ghi đè <khoá boss>.glb. Boss ma thần: thêm maton.glb, thienma.glb, huyetma.glb, thienloithan.glb, cuuthienhuyennu.glb.
  - Tên động tác trong file (không phân biệt hoa thường): idle/stand · run/walk/fly · attack/slash · cast/spell · hit/damage
    · die/death · meditate/sit · victory/win · roar · rage.
  - Vật liệu tên robe_main / robe_inner / robe_trim / hair_extra sẽ được game đổi màu theo lớp.
  - Xoá file thì game tự quay về bản dựng bằng code.
  - Chỉ dùng model bạn có quyền dùng trên live.
